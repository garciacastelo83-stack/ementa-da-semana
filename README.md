# Ementa da Semana

Aplicação para planear a ementa semanal da família, a lista de compras, os nutrientes e o registo das refeições e da água.

## Instalar no Android

1. Abra a página **Releases** deste repositório (à direita, ou em `/releases/latest`).
2. Descarregue o ficheiro `EmentaDaSemana-1.X.apk`.
3. Abra o ficheiro no telemóvel e toque em **Instalar**. Se o Android pedir, autorize a instalação a partir do Chrome ou do gestor de ficheiros.

Cada vez que a app é actualizada, aparece uma nova versão em Releases. Basta instalar por cima: os dados mantêm-se.
